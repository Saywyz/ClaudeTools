Claude, directement dans votre code.

À quoi ressemble le travail avec lui

Ouvrez le projet

Lancez Claude Code dans le dossier sur lequel vous travaillez. Il voit vos fichiers.

Dites ce que vous voulez

En français : « ajoute une connexion », « corrige cette erreur », « écris des tests ».

Validez les changements

Claude montre ce qu'il va modifier ou exécuter. Vous confirmez avant qu'il agisse.

Testez & affinez

Lancez, donnez votre avis, et bouclez jusqu'à ce que ça marche comme prévu.
